# 🎨 Samridha's Art Portfolio

A responsive art portfolio website with vintage-inspired design showcasing original artwork.

## ✨ Features

- Responsive gallery with intelligent aspect-ratio preserving layout
- Elegant vintage aesthetic with warm color palette
- Smooth navigation with animated hover effects
- Fully mobile-optimized
- Custom typography using Google Fonts

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts: Dancing Script, Crimson Text, Libre Baskerville
- Dynamic image layout algorithm

## 📁 Structure

```
├── index.html          # Main HTML
├── style.css           # Styling and responsive design
├── script.js           # Gallery layout algorithm
├── assets/             # Artwork images (39 files)
└── README.md
```
